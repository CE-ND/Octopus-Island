# 隐私与安全

## 本机数据

Octopus Island 默认在 `%USERPROFILE%\.octopus_island` 保存用户设置、待办、本机日程及提醒设置、饮水记录、置物文件路径、连接元数据以及忽略的邮件日程标识。首次启动且新目录不存在时，自动复制旧 `%APPDATA%\OctopusIsland` 数据并保留原目录作为备份；已存在的新目录不会被旧数据覆盖。环境变量 `OCTOPUS_ISLAND_DATA_DIR` 可指定另一目录，显式指定时不执行自动迁移。置物架保存原文件路径，不复制文件正文。本机日程不上传到工作日历。

邮箱和日历密码通过 Windows 凭据管理器保存；独立 Gemini 会话使用当前 Windows 用户的 DPAPI 加密。连接元数据中可能包含邮箱地址、账号名称和本机登录文件路径，因此整个数据目录都不适合公开上传。

程序读取收件箱内的邮件以展示正文、提取验证码与日历邀请。当前邮件记录保存在内存中；不要将运行中的内存转储公开分享。

## 网络访问

AI 编程助手状态提醒通过 Claude Code 或 Codex 的官方 hooks 在本机传递状态。启用后，Octopus Island 会在对应助手的配置目录安装自己的脚本和 hook 条目；Codex 使用独立的 `hooks.json`，不改动其登录文件或 `config.toml`。事件只保存助手类型、状态、工具名、会话／轮次／工具调用 ID、项目文件夹名和时间。每轮开始时可只读查询父进程链的名称、PID 和创建时间，以识别所属助手；识别结果保存在本机会话元数据文件中，用于监听进程退出。不保存提示词、工具参数、回复正文、进程命令行或登录令牌，也不向网络发送这些数据。事件使用独立文件避免并行覆盖，读取后删除；Octopus Island 未运行时积压队列保留最新 512 条，监听时清理超过 12 小时的记录。会话元数据在会话正常结束时删除；关闭对应助手开关会移除 Octopus Island 的 hooks、脚本和事件目录，保留原有配置及信任记录。

音乐兼容功能会只读访问汽水音乐、酷狗音乐的本机歌词缓存，以及网易云音乐的本机播放日志和播放队列；酷狗配置仅用于提取歌词目录。只保留歌词、歌曲 ID、歌名、歌手、专辑、公开封面地址、播放状态和时间轴，缺少系统封面时会从网易云图片服务获取专辑缩略图。日志正文、音频签名链接等内容不会保存或上传。网易云原生播放事件不依赖 SMTC 或固定内存地址；必要时仍可对已匹配的网易云、酷狗版本只读获取播放进度。不会修改播放器、读取音频或提取登录信息。启动或运行异常的诊断日志保存在数据目录的 `diagnostics/last-error.log`，不会自动上传。

启用对应功能后，程序会联系邮箱 IMAP 服务、工作日历 CalDAV / Exchange ActiveSync 服务、AI 服务额度接口以及歌词服务。连接方式和服务器见源码中的 `mail.rs`、`calendar.rs`、`quota.rs`、`lyrics.rs` 及对应 provider 模块。

点击「检查更新」时，程序会访问 GitHub 的公开发布接口，并在请求头中包含 Octopus Island 版本号，不发送本地设置、邮箱或日程数据。选择「下载并安装」会从 GitHub 下载公开安装包至 `%LOCALAPPDATA%\OctopusIsland\Updates`，核对大小及 SHA-256 后替换程序并重启；「浏览器下载」通过默认浏览器打开发布页。

程序不使用统一的 Octopus Island 云端账号，也没有项目自建的邮件或日程上传后台。第三方服务自身的数据处理政策仍然适用。

## 登录凭据

本机 AI 客户端的登录文件只读使用，不修改原客户端配置或替它刷新登录。独立连接的凭据由 Octopus Island 自己的安全存储管理。不要把 Cookie、授权码、登录 JSON、凭据文件、真实邮件或私人日程提交到 GitHub。

## 反馈安全问题

请使用仓库的私密漏洞报告入口，见 [SECURITY.md](../SECURITY.md)。普通 UI 问题可以开公开 Issue，但请先去除敏感信息。
